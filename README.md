# CityCat · חתולי תל אביב

אב-טיפוס לאפליקציית מיפוי חתולי רחוב בתל אביב-יפו: סריקת חתול וזיהוי, אווטר ותעודת זהות, מפה עם שכבות, דיווחי מצוקה, כלבים משוטטים, איסוף גופות לתברואה, אימוץ, ניקוד, משחק ופאנל מנהל אזור.

האתר הוא קובץ HTML סטטי אחד, בלי שלב build.

## העלאה ל-Vercel
1. ב-[vercel.com/new](https://vercel.com/new) בוחרים את הריפו `CityCat`.
2. Framework Preset: **Other**. אין Build Command ואין Output Directory.
3. Deploy.

## התקנה בטלפון (PWA)
- **אנדרואיד (Chrome):** נפתח חלון "התקן את CityCat", או בתפריט ⋮ ← "התקנת אפליקציה".
- **אייפון (Safari):** שיתוף ← "הוספה למסך הבית". האפליקציה מציגה הנחיה כזו בעצמה.

## מפה
- ברירת מחדל: OpenStreetMap, ומפת Esri כגיבוי. שתיהן בלי מפתח.
- Google Maps (דורש חשבון חיוב בגוגל): לוחצים על "מפה:" בפינת המפה ומדביקים מפתח Maps JavaScript API. המפתח נשמר רק בדפדפן.

## מגבלות האב-טיפוס
- הנתונים לדוגמה ונשמרים בדפדפן בלבד (localStorage). אין שרת משותף.
- הזיהוי באתר הציבורי הוא מקומי (צבע וטביעת אצבע חזותית). זיהוי עם Claude זמין בגרסת claude.ai.
- "עמותת חתולי העיר" היא עמותה לדוגמה.
